# 💸 现金流小富翁 · Cashflow Kids

> 一款给 **6–14 岁孩子和家庭**玩的财商启蒙网页桌游。
> 目标只有一个：**让被动收入 ≥ 生活支出**，实现财务自由。

🎮 **在线试玩**：把本仓库开启 GitHub Pages 后即可直接打开
（`Settings → Pages → Source: main / root`）

---

## 为什么做这个游戏

大多数孩子（甚至很多成年人）分不清 **资产** 和 **负债**：

| 常见误解 | 游戏里教会孩子的事实 |
| --- | --- |
| 房子就是资产 | 自住房每月从口袋拿钱 → 是**负债**；出租房每月送钱 → 才是资产 |
| 工资高就有钱 | 高工资 + 高支出 = 依然是月光；关键是**净现金流** |
| 存款越多越好 | 现金被通胀悄悄吃掉；现金要变成**会生钱的资产** |
| 借钱是坏事 | 借钱买「能赚钱的东西」叫杠杆，借钱买「会贬值的东西」叫负担 |
| 省钱就能变富 | 变富靠的是**现金流结构**，不是单纯抠门 |

游戏把这些抽象概念，变成了一局可以在 20 分钟内玩完的桌面游戏。

## 玩法速览

### 🎯 胜利条件
**被动收入 ≥ 每月生活费** —— 达成即「财务自由」。

注意一个刻意的设计：**这里的「生活费」包含房贷月供利息**。
也就是说，靠借钱堆出来的房子，会把「自由线」一起抬高。
这点跟真实的财务自由计算方式一致 —— 也让「负债」的代价看得见。

> 若开启回合上限（三种难度分别为 45 / 55 / 70 回合），
> 回合结束后按 **自由进度**（被动收入 ÷ 生活支出）排名，而不是按谁最有钱。
> 因为本作想教的是现金流，不是比富。

### 💰 月度现金流公式

```
净现金流 = 工资收入 + 被动收入 − 生活支出 − 负债利息
```

### 🏦 负债的月供利息

| 负债类型 | 月利率 | 说明 |
| --- | --- | --- |
| 🏠 按揭贷款（买房） | 3.2% | 首付之后的贷款余额按此计息 |
| 💳 个人消费贷 | 2.0% | 部分职业出生自带 |
| 🆘 紧急贷款 | 3.0% | 现金变负时被迫借，额度 12,000 |

借钱买房会永久占用你每个月的现金流。游戏会在买入弹窗里
**直接显示「月供利息」和「每月实际净收入」**，避免孩子误以为
「租金 1,000 元」就等于「每月多赚 1,000 元」。

### 🎲 回合流程
掷骰子前进 → 落格触发事件 → 经过「领工资格」结算月度现金流 → 下一位玩家。

### 🗺️ 38 格环形棋盘

| 格子 | 作用 |
| --- | --- |
| 🏁 **起点** | 每绕行一圈领取完成奖励 |
| 💰 **领工资** | 结算月度现金流（走过也算） |
| 💡 **小机会** | 用现金买入起步型资产 |
| 🏗️ **大机会** | 不动产 / 大生意，可用**首付 + 贷款**撬动 |
| 🛍️ **消费** | 分清「需要」和「想要」 |
| ⚡ **意外支出** | 有保险可理赔 80% |
| 📊 **市场风云** | 宏观事件，**所有玩家**同时受影响 |
| 💼 **副业** | 主动收入，时间换钱 |
| 📚 **学习进修** | 永久提高工资 / 资产收益 |
| 💝 **慈善捐赠** | 捐款获得「善缘」（移动 +1 步） |
| 🏦 **银行** | 买保险、提前还债 |
| 🌈 **梦想之角** | 花钱实现人生梦想 |

## 🧮 核心教育设计：两张财务报表

这是本游戏最有价值的部分 —— 屏幕左下方永远有**真实的财务报表**可查。

### 收支表（Income Statement）
```
收入
  💼 工资收入（主动收入）      +9,500
  🏠 小户型出租房（租金）        +950
  📊 宽基指数基金               +40
  📈 被动收入合计              +990
  收入合计                   +10,490

支出
  🍚 生活支出（吃住行学费）     −4,600
  🏦 按揭贷款（月供利息 3.2%）    −180
  支出合计                    −4,780

💰 每月净现金流               +5,710
🎯 财务自由线：被动收入 ÷ 生活支出   22%
   （达到 100% 就实现财务自由；注意：被动收入要单独盖住生活费，不能靠工资帮忙）
```

### 资产负债表（Balance Sheet）
```
资产
  💵 现金                    25,000
  🏠 小户型出租房              215,000
  资产合计                  240,000

负债
  🏦 按揭贷款               −155,000
  负债合计                 −155,000

🏛️ 净资产                     85,000
```

> **给孩子的一句话**：现金流是**水管**，净资产是**水池**。
> 水管越粗，水池迟早会满。

### 三种难度的差异

| 难度 | 起始现金 | 通胀/年 | 意外强度 | 借款利率 | 回合上限 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 🌱 轻松 | ×1.6 | 1.5% | ×0.6 | ×1.0 | 45 |
| ⚖️ 标准 | ×1.0 | 3.0% | ×1.0 | ×1.0 | 55 |
| 🔥 硬核 | ×1.0 | 7.0% | ×1.8 | ×1.25 | 70 |

硬核难度的重点不是「机会更贵」，而是**通胀跑得更快** ——
你会真切体会「跑不赢通胀」的焦虑，以及为什么必须先有被动收入。

### 刻意的难度上限

- **单笔意外支出 ≤ 1 个月总开销**：可预期、可承担，才谈得上学得会
- **生活费通胀封顶 3 倍**：避免后期开支失控把游戏拖成死局
- **永久加息最多累计 3 次**：利率不会被推到荒谬的高度
- **市场风云是「当月一次性」的**：涨跌按「你这类资产的当月收入」计算，最多影响一两个月收益。
  真正留下长期伤口的只有两件事：**永久性物价上涨**，和**永久性利率上调**

## 🚀 本地运行

因为使用 ES Module 之外的普通 `<script>`，**直接双击 `index.html` 就能玩**。

如果想用本地服务器（推荐，避免个别浏览器的本地文件限制）：

```bash
# Python 3
python -m http.server 8000

# 或 Node.js
npx serve .
```

然后打开 <http://localhost:8000>

### 部署到 GitHub Pages

1. 把本仓库推送到 GitHub
2. 进入 `Settings → Pages`
3. **Source** 选择 `Deploy from a branch`
4. **Branch** 选 `main`，目录选 `/ (root)`
5. 保存后等待 1 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`

## 🛠️ 自定义（老师 / 家长向）

**所有游戏内容都集中在 `js/data.js`**，不需要懂编程也能改：

| 想改什么 | 改哪里 |
| --- | --- |
| 增加职业 | `CAREERS` 数组 |
| 增加资产 / 机会卡 | `SMALL_OPPS` / `BIG_OPPS` |
| 增加消费项目 | `SPEND_CARDS` |
| 增加意外事件 | `ACCIDENT_CARDS` |
| 增加市场事件 | `MARKET_EVENTS` |
| 增加学习课程 | `STUDY_OFFERS` |
| 增加梦想 | `DREAMS` |
| 增加财商知识点 | `TIPS` |
| 增加徽章 | `BADGES`（需同步在 `game.js` 的 `BADGE_CHECKS` 加判定） |
| 调整难度曲线 | `MODES` |

例如，想加一个新的资产：

```js
{ id: 's_bakery', name: '面包房', icon: '🥐', cost: 22000, income: 520,
  unit: '间', tags: ['biz'],
  desc: '每天早上都有人排队。', risk: '中',
  teach: '重资产型生意现金流很稳，但投入也大。' },
```

> `cost` 投入成本 ｜ `income` 每月被动收入 ｜ `tags` 用于市场事件匹配
> （`paper` 纸资产 / `realestate` 不动产 / `biz` 生意 / `cash` 现金设备 / `royalty` 版权）

## 🎓 教学建议

**给家长**：
1. 第一局陪孩子玩，边玩边问「这笔钱花得值吗？」
2. 每次领工资时，一起看**收支表**，问「这个月存下多少？」
3. 遇到消费格，问「这是需要还是想要？」
4. 游戏结束后，对照结算页的 5 条要点复盘。

**给老师**：
- 可让学生分 4 组对战，15 分钟一局
- 结束后要求每组用「收支表」和「资产负债表」写一段财务分析
- 对比不同难度下的财务自由难度，引出「通胀」概念

**讨论题**（可直接用于课堂）：
1. 为什么游戏里自住房不算资产？
2. 为什么「还掉高息负债」等于「稳赚不赔的投资」？
3. 为什么被动收入比工资更重要？
4. 应急基金为什么必须是现金，不能是房子？
