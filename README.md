## 📌 关于「像不像大富翁4Fun」

**规则层面高度还原，美术与音频全部原创。**

玩法机制（掷双骰、买地盖房、收租、股票、卡片、乐透、神明、拍卖、交易、物价指数）属于「规则/思想」，可以学习实现；但**角色形象、立绘、配音、音乐、地图美术、UI 和「大富翁」名称**是原作版权/商标，且本仓库公开，因此**不使用任何原版素材**。目标是「玩法玩起来像，画面是我们自己的」。

**v3 一期已把原版缺失的经济节奏补齐；v3.1 起进入二期视觉重制**（2.5D 立体地块与 L0–L5 等距建筑、证券交易所暖白纸张 UI）；**v3.2 把股市行情换成了符合量价体系的真实 K 线**。Q 版原创角色、更多地图、设置页 / 报表重制仍在推进。100% 像素级复刻既不现实，也不合规。

## 🆕 v3.2 更新：符合量价体系的真实 K 线

v3.1 的 K 线「能画出来」但**不像真实股市**：股价是随机游走、开高低收由收盘价反推，没有成交量，走不出任何技术形态。v3.2 把行情生成层整个换掉。

### ① 量价引擎（新增 `js/game/market.js`）

阶段状态机驱动，一个完整周期约 30–45 根：

`吸筹 → 放量突破 → 趋势 → 顶部派发 → 下跌 → 整理平台 → 再突破`

每根 K 线同时决定价格与成交量，遵守量价体系：

| 阶段 | 价格特征 | 量能特征 |
|---|---|---|
| 吸筹 / 整理 | 小阴小阳、振幅收敛、长下影 / 锤子线 / 十字星 | 逐根缩量到**地量** |
| 突破 | 放量长阳（或破位长阴）+ 跳空缺口 | 量比 **2–4 倍** |
| 趋势 | 高点低点依次抬高，缩量回调不破均线 | **价涨量增 / 价跌量缩** |
| 派发 | 价创新高但收不住，长上影 / 放量滞涨 | **量价背离**（缩量） |
| 下跌 | 首根放量长阴杀跌，之后缩量阴跌 | 跌放量、反弹无量 |

生成锤子线、射击之星、十字星、红三兵等形态，并用 MA5/10/20、量比、MACD 做**形态识别**，在面板输出技术信号（金叉死叉、多头排列、放量突破、量价背离、地量地价等）。

- 股价保留**两位小数**（真实股市口径），解决 8 元低价股被整数取整抹平波动的问题；
- 开局预置 **40 个营业日**完整行情，末根等比缩放收回基准价，游戏平衡不变；
- K 线最多保留 80 根、图上显示最近 40 根，MA20 / MACD 才有意义；
- 旧存档自动补 OHLCV 与引擎状态。

### ② 专业组合行情图

对齐国内行情软件：主图（**阳线红框空心 / 阴线绿实心** + MA5/10/20 + 价格网格与右侧刻度 + 最新价虚线）、**VOL 成交量副图**（量柱 + VMA5/10）、**MACD(12,26,9) 副图**（DIF/DEA + 红绿柱），三区共用 X 轴。

- 盘口八项：今开 / 昨收 / 最高 / 最低 / 成交量 / 量比 / 换手 / 振幅；
- **十字光标**：鼠标移入显示该日四价、涨跌、振幅、量比、形态与所处阶段；
- **日K / 周K** 切换（周K 由每 5 个营业日聚合）；
- 点股票行切换主图，4 行内嵌缩略 K 线；
- 技术信号卡 + 量价四句口诀，把「为什么这个形态要看量」讲给孩子听。

> 验证：量价引擎独立验算 200 轮 × 4 只股票（32,000 根 K 线）全部通过；浏览器全量回归 **77 通过 / 0 失败 / 0 控制台错误**。

## ✨ 游戏理念

「收租」是财商启蒙最好的比喻：**让资产替你工作**。

- 每块地都是一只会下蛋的鹅，别人踩上去付的过路费就是**被动收入**
- 右侧报表常驻，把「主动收入（津贴）/ 被动收入（租金、分红）/ 支出 / 负债」分开列，孩子能亲眼看到结构变化
- 破产不是运气差，而是**现金垫太薄 + 负债太重 + 资产变现太慢**——结算屏会逐一点评

## 🎮 玩法说明

| 系统 | 说明 |
|------|------|
| 🎲 **双骰与连掷** | 两颗骰子决定步数；同点再来一轮（不加一天），连续三次同点直接入狱；狱中只有掷出同点才能出狱 |
| 📅 **日历与休市** | 每人走一轮 = 1 天；小镇历 15 天 = 1 月。周六日 + 每月 8 号休市，股市、银行不营业 |
| 📊 **物价指数** | 月底按「全员平均基础净资产 ÷ 开局均值」重算，上限 ×6。指数上涨时地价、过路费、盖房费、事件金额同步上涨——后期真正难的不是买不起地，是付不起租 |
| 🏠 **买地盖房** | 无主地按公定价买下（含指数）；可加盖到 **L5 星级酒店**；同街每多一块地 +15% 连锁租金，集齐全街 ×2；不买会被银行拿去**公开拍卖** |
| 🔨 **拍卖与交易** | 拍卖可参与竞价（三档最高出价）；操作台「🤝 交易」可用空地 + 现金差额和 AI 换地，AI 会按「能否凑成垄断」估值决定接受与否 |
| 🏦 **银行** | 存取款；贷款 3 个月（45 天）**不收利息**，但借款期间存款停止计息，到期强制归还；每月 15 号按存款 **10%** 结息 |
| 📈 **股市** | 4 只股票（波动率从低到高），营业日随机游走 + 均值回归；休市日只能看盘；每月底按持仓市值 2% 分红；SVG 走势图，涨红跌绿 |
| 🎰 **乐透** | 自选 1-12 号投注（500 元/注），每月 15 号开奖；命中者平分奖池，无人中奖全额滚存；付给银行的罚款 20% 注入奖池 |
| 🃏 **32 张卡片** | 控制步数（遥控骰子/机车/传送/再来一次/路障）、地产经营（购地/换地/涨价/加倍/查封/拍卖/怪兽/炸弹）、陷害防御（梦游/定时炸弹/入狱/住院/查税/抢夺/免费/免罪/守护）、财运（红包/均富/内线/彩票）、请神（土地公/天使/恶魔） |
| 🎫 **点券与小游戏** | 落到游乐场玩**接金币 / 射神明 / 猜兔子**赢点券，点券可在道具店换卡；卡片格、命运事件也会送卡 |
| ✨ **8 位神明** | 财神（收入 ×2）、福神（挡厄运）、土地公（所到之地据为己有）、天使（路过自己的地免费加盖）、穷神（收入减半）、衰神（每回合扣钱）、恶魔（路过拆一层）、恶犬（咬进医院）；30% 概率为持续更久的「大神」 |
| 🔮 **魔法屋** | 女巫随机选中一人，由你决定破财 / 牢狱 / 住院 / 拆房 / 失卡 / 补税 |
| 🏆 **胜负** | 让所有对手破产，或天数走完时总资产最高。结算屏含排名、逐一点评与「大亨三条铁律」 |
| 💾 **存档** | localStorage 自动保存（含日历、物价指数、乐透选号），支持刷新续玩与读档 |

## 🎨 美术（一期现状）

- **棋盘**：15×7 外圈 40 格，CSS Grid 程序化生成，街区色带、产权小旗、地台投影

## 🛠 技术特点

- **零依赖单页应用**：原生 HTML/CSS/JS，无框架、无构建、无外部请求，克隆即可玩
- **显式状态机** `G.phase`（idle → rolling → moving → landing → idle-post → turnEnd → over）
- **推进脱离调用栈** + 双层看门狗（`watchTimer` / `endWatchTimer`），防止全 AI 连续对局停滞
- **AI 路径零交互弹窗**：所有卡片、神明、小游戏、拍卖对 AI 都有自动结算路径
- **存档结构校验 + 自动修补**，v2 旧档可直接升级读取

## 🎓 自定义指南（老师 / 家长）

全部内容**数据驱动**，改这两个文件即可调整游戏：

| 想改什么 | 改哪里 |
|----------|--------|
| 地价、租金、盖房费、街区划分、角色初始现金 | `js/data/world.js` → `MAP` / `rentOf` / `CHARACTERS` |
| 局时长、月长度、休市日、存款利率、物价指数上限、乐透号码范围 | `js/data/world.js` → `BALANCE` |
| 卡片价格 / 效果 / 教学文案 | `js/data/content.js` → `CARDS` |
| 神明、命运事件、新闻事件、小游戏 | `js/data/content.js` → `GODS` / `CHANCES` / `NEWS` / `MINIGAMES` |
| 股票数量、波动率、教学语 | `js/data/content.js` → `STOCKS` |

租金表自动按地价计算：`[6%, 11%, 24%, 42%, 62%, 88%]`（空地 → L5 酒店），再叠加同街连锁、垄断 ×2、新闻倍率与物价指数。
